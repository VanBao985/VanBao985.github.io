Dán GitHub Personal Access Token để có quyền tải ảnh lên repo.

Token được lưu trong localStorage của trình duyệt này, không bao giờ được commit vào repo.

Cách tạo token (lần đầu)
  1. Mở github.com/settings/personal-access-tokens/new
  2. Token name: đặt tên gì cũng được, ví dụ ki-uc-dai-hoc
  3. Expiration: chọn thời hạn (hết hạn thì tạo lại token mới)
  4. Repository access → Only select repositories → chọn VanBao985.github.io
  5. Permissions → Repository permissions → tìm Contents → đổi thành Read and write
  6. Bấm Generate token, copy chuỗi hiện ra rồi dán vào ô trên

Chuỗi token chỉ hiện một lần duy nhất — nếu lỡ mất thì tạo cái mới.
